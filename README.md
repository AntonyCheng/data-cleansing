# 多模态数据清洗台

面向图片、音频、视频的结构化数据清洗工具：上传原始素材，自动产出可直接使用的结构化数据、文字转写与内容摘要。

## 能干什么

**图片**
- 自动识别版式（发票、证件等常见票据/证照，以及通用图片）
- 结构化抽取关键字段并附带置信度，支持在页面上直接手动修正
- 输出全文 OCR、图片摘要与标签
- 结果可下载为 JSON

**音频**
- 转写全文，自动分说话人、带精确时间戳
- 自动生成摘要、要点、待办事项
- 结果可下载为 JSON / SRT 字幕 / 纯文本全文

**视频**
- 边播放边分析：字幕与画面事件实时同步显示
- 播放结束自动生成章节划分与整片摘要
- 结果可下载为 JSON / SRT 字幕

**通用能力**
- 任务提交后在服务端持续处理，切换页面或关闭浏览器不会中断，重新打开可继续查看进度或结果
- 同一时间每种类型（图片/音频/视频）最多处理一个任务，不同类型互不影响、可同时进行
- 本地历史记录，随时回看、支持单条删除
- 界面简洁清爽，适合对外演示

## 快速开始

需要 Docker。

```bash
git clone https://github.com/AntonyCheng/data-cleansing.git
cd data-cleansing
cp .env.example .env   # 按提示填写所需的服务密钥
docker compose up -d --build
```

打开 <http://localhost:8080> 即可使用。`samples/` 目录下提供了图片 / 音频 / 视频三个示例文件，可直接用于体验。

未填写密钥时会自动使用内置示例数据，方便先熟悉界面和流程。

## 本地开发（不使用 Docker）

```bash
npm install
cp .env.example .env
npm run dev   # 前端 http://localhost:5173，后端 :8787
```
